authentication
    earn token by login with email and password
    save token in localstorage
    load me and all profiles from the server
    select a profile
    save profile ID in localstorage

check authentication when loading pages
    set login status to pending
    check token in localstorage
    if token does not exist redirect to login page
    else load me from server
    if a load fails to redirect to home page and set login status to false
    check if profile ID is in localstorage
    if not redirect to profile page selection
    else load profile from server
    if a load fails to redirect to profile page selection
    set login status to true

reset password
    enter email
    call api get OTP and show ui input
    after user enters OTP call api validate OTP
    if invalid show an error message
    else show form to enter new password
    send new password and verify token to api
    if api returns error show an error message
    else redirect to login page
